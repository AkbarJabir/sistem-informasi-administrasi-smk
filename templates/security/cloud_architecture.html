Uraian Komponen & Prinsip Zero Trust

1. Perimeter Defense (DDoS & WAF)

Fungsi Utama: Berada di garis terdepan untuk memfilter traffic internet sebelum menyentuh aplikasi.

  • DDoS Protection: Mitigasi serangan flood Layer 3 & 4 (SYN Flood, UDP Reflection).
  • Web Application Firewall (WAF): Memblokir payload berbahaya Layer 7 seperti SQL Injection, Cross-Site Scripting (XSS), dan Path Traversal.
  • Rate Limiting: Mencegah brute-force pada endpoint /login dan /mfa-verify.
Pemetaan Cloud: AWS WAF + AWS Shield / GCP Cloud Armor
2. Public Subnet & Application Load Balancer

Fungsi Utama: Menerima traffic publik terenkripsi (HTTPS) dan mendistribusikannya ke instance aplikasi di private subnet.

  • TLS Termination: Memastikan seluruh data in-transit terlindungi dengan protokol TLS 1.3.
  • Reverse Proxy: Menyembunyikan alamat IP dan topologi internal server backend dari publik.
  • Health Checks: Memonitor ketersediaan container aplikasi secara kontinu.
Pemetaan Cloud: AWS Application Load Balancer (ALB) / Google Cloud Load Balancing
3. Private Subnet: Zero Trust Policy Enforcement

Fungsi Utama: Menjalankan logika bisnis administrasi SMK dengan menerapkan prinsip "Never Trust, Always Verify".

  • Contextual RBAC: Setiap request diperiksa role dan izinnya di level middleware, bukan sekadar menyembunyikan tombol UI. Akses tidak sah menghasilkan 403 Forbidden.
  • Multi-Factor Authentication (MFA): Diwajibkan bagi akun administratif (Staf TU & Kepala Sekolah).
  • Least Privilege Access: Siswa hanya bisa membaca nilainya sendiri; Guru hanya dapat mengelola nilai; Kepala Sekolah berwenang menyetujui ijazah.
Pemetaan Cloud: AWS ECS/EKS / Google Kubernetes Engine (GKE) / Cloud Run
4. Isolated Data Subnet & Key Management

Fungsi Utama: Menyimpan data tabular dan mengelola kunci kriptografi secara terisolasi tanpa akses langsung dari internet.

  • Encryption at Rest: Database dan file upload dienkripsi menggunakan kunci KMS yang dirotasi secara otomatis.
  • Network Isolation: Port database hanya terbuka bagi security group container aplikasi di private subnet.
  • Audit Logging: Seluruh aktivitas administratif dan perubahan nilai dicatat secara permanen ke tabel audit_logs.
Pemetaan Cloud: Amazon Aurora PostgreSQL / Cloud SQL + AWS KMS / Cloud KMS
5. Blockchain Subnet & Smart Contract Document Verification

Fungsi Utama: Menjamin integritas dan keabsahan dokumen penting (Ijazah, Transkrip, Sertifikat PKL) melalui sidik jari kriptografis.

  • Off-Chain Storage, On-Chain Hash: File fisik PDF disimpan di storage terenkripsi, hanya hash SHA-256 (32 byte) yang dicatat ke ledger.
  • Smart Contract Authorization: Fungsi issueCertificate() hanya dapat dieksekusi oleh wallet Kepala Sekolah terotorisasi; request dari pihak luar ditolak dengan Transaction Reverted.
  • Reentrancy Guard: Smart contract dilengkapi proteksi mutex untuk menangkal eksploitasi reentrancy.
  • Public Trustless Verification: Universitas dan industri dapat memverifikasi PDF secara publik tanpa memerlukan akun login.
